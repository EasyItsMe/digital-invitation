Konfigurasi Database Cloud (Supabase)

Hubungkan undangan digital Anda ke Supabase (100% Gratis & siap deploy ke Vercel) agar konfirmasi kehadiran dan ucapan tamu otomatis tersimpan dan sinkron antar-semua HP/perangkat.

💡 Petunjuk Cepat:
1. Buat project gratis di supabase.com
2. Buka menu Project Settings > API, lalu salin Project URL dan anon public key ke atas.
3. Jalankan query dari file supabase_schema.sql di menu SQL Editor Supabase.
Berhasil!
